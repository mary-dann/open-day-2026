# Лендинг "День открытых дверей в РГАТУ имени П. А. Соловьева"

## Задание
Сверстать по макету лендинг «День открытых дверей в РГАТУ имени П.А.
Соловьева».

## Инструменты: 
- vite - помогает быстро запустить сайт во время разработки, собирает файлы в готовый проект перед публикацией
- Tailwind - CSS-фреймворк, нужен для быстрого написания стилей
- Prettier - делает код красивым (расставляет пробелы и отступы)
- ESLint и Stylelint - проверка кода на ошибки


## Что сделано 
1. Настроен проект: подключены инструменты сборки и проверки кода.
2. Настроены линтеры.
3. **Первый экран (Hero):**
   * Сверстана композиция с диагональным разделением белой и синей частей. Диагональ сделана с помощью `clip-path`.
   * Красная плашка «Приглашаем» реализована как отдельный блок и срезом правого края. 
   * Белая плашка `rsatu.ru` вынесена наружу через `absolute` и `z-index`, чтобы `clip-path` не обрезал её края.
   * Для адаптивности используются `flex` и `grid` с медиазапросами (на мобильных всё перестраивается в столбик, но нужно еще поправить).
4. **Два преимущества (Features):**
   * Сверстаны две текстовые колонки. Заголовки оформлены в овальные рамки с помощью `rounded-full`, `border-2` и `text-primary`.
   * Используется `grid` для разделения на две колонки на десктопе (`flex-col` для мобильных).
5. **Образовательные программы (Programs):**
   * Список из 12 программ обернут в карточку с синей рамкой (`border-2`, `rounded-[2rem]`).
   * Бирюзовые маркеры реализованы через псевдоэлемент `::before` с `rounded-full` и `bg-accent`.
